不熄！ / LitRun! 3.0.0

首次启动选择中文或 English，之后可在齿轮设置中即时切换。
窗口顶部以 LitRun!、状态点和状态文字组成紧凑的一行；Dock 仍使用完整彩色图标。
电脑用电、充电输入、内存占用、磁盘占用和芯片温度保持为紧凑、居中的五列读数。
合盖运行与低功耗使用原生 macOS 开关并排显示，完整风扇控制集中在下一行。
手动风扇：仅在只读探测确认固件支持后开放，一个滑条同步调节所有可控风扇。
风扇百分比会跟随拖动实时变化，停止拖动后再写入最终目标，避免连续调用管理员组件。
合盖运行：保持任务和网络连接，不会自动降速。
低功耗：根据功耗与温度自动加深慢跑，任务始终保留运行时间。
芯片温度：窗口单独成列，菜单栏可与其他读数分行显示；无法读取时回退到系统热状态。
窗口以五列分别显示电脑用电、充电输入、内存、磁盘和芯片温度；内存与磁盘每 10 秒通过系统 API 轻量刷新。
顶部栏：功耗行只显示整数瓦数，例如 20 W；设置可分别勾选功耗、温度、风扇、内存、磁盘和网速，也可以全部取消。全部取消后状态栏指标隐藏，仍可从窗口齿轮重新开启；默认五项使用两行对称排列，网速按需开启；网速只读取活动网卡字节计数，不记录网络内容。

首次使用管理员功能需要一次授权，之后无需重复输入密码。
无风扇机型自动禁用风扇控制；无电脑盖机型自动禁用合盖运行。
红色关闭按钮隐藏窗口，App 继续在菜单栏后台运行。
黄色按钮使用系统原生最小化；启动、隐藏、恢复、开关和状态文字采用克制动效，并遵循“减少动态效果”。
菜单栏“退出软件”会恢复自动风扇和电源设置后退出。
切换过程中请求退出会在当前操作安全完成后自动继续，不会表现为点了没反应。
关闭合盖运行会恢复开启前的完整防休眠状态，不会固定关闭其他软件原本设置的防休眠。
异常退出时，电源、风扇和已调暗的内屏都有独立恢复机制。

安全提醒：低于 50% 会先警告；芯片达到 99°C 或 macOS 报告升温/严重过热时会恢复自动温控。
当前 ad-hoc 签名包仅供技术测试；普通用户分发需要 Developer ID 签名和苹果公证。
