# 不熄！ / LitRun!

一个极简的 macOS 菜单栏工具，让任务按需合盖续跑，并提供独立低功耗和手动冷却。

首次启动选择中文或 English，之后可在齿轮设置中即时切换。窗口顶部以紧凑的 `LitRun!`、状态点和当前状态组成一行，Dock 与 Finder 使用完整彩色图标。电脑用电、充电输入、内存占用、磁盘占用和芯片温度保持为紧凑、居中的五列主读数，下方紧跟一行较小的实时网速副读数。

## 三个控制

- **合盖运行**：合盖后保持运行和网络连接，不会自动降速。
- **低功耗**：根据功耗与温度自适应加深后台慢跑，始终保留短暂运行窗口，开盖、合盖都可单独使用。
- **风扇控制**：只读探测确认固件开放手动模式后才启用，用一个滑条同步调整所有可控风扇，支持 0-100%；无风扇或仅支持读取的机型会自动禁用开关。

低功耗只处理明显高负载的后台任务，并保护当前前台 App、它的子进程和同一 App 包内的渲染/辅助进程。每次短暂停顿都有独立恢复守护；关闭模式、App 异常退出或守护收到终止信号时都会恢复任务。它是尽量降低后台负载的兼容策略，不是硬件级功耗上限。

窗口用五列仪表分别显示电脑自身用电、充电器进入 Mac 的总输入、内存占用、磁盘占用和芯片温度；说明文字与数值分层排列，单位以更小字号嵌入读数，两项功率都不显示约等号。五列下方以更小字号显示实时网速，例如 `网速  ↓2.1k ↑1k`，完整单位和状态仍可通过提示查看。内存与磁盘每 10 秒通过 macOS 系统 API 轻量刷新，不会持续启动外部命令。合盖运行与低功耗使用原生 macOS 开关并排显示，风扇控制在下一行集中显示图标、名称、转速、滑杆、百分比、开关和自动/手动状态。风扇滑杆保留系统式轨道和圆形滑块，百分比跟随拖动实时变化，停下后才写入最终目标。顶部栏的功耗行只显示整数电脑用电，例如 `20 W`。齿轮设置提供功耗、温度、风扇、内存、磁盘和网速六个可选项，可以全部取消；全部取消后状态栏指标隐藏，但仍可从窗口齿轮重新开启。新安装默认显示前五项，网速按需打开。默认五项使用两列纵向 3+2 网格，六项使用两列纵向 3+3 网格，最多显示上中下三行，不使用三列；五项包含网速时，网速固定在左列最下面，六项时网速固定在右列最下面；较矮的菜单栏自动缩小，避免裁切。每个指标使用独立固定槽位，网速不会把同一行的其他指标撑宽，速率变化也不会造成菜单栏抖动。网速每秒读取活动物理网卡的收发字节计数，只计算下载/上传速率，不启动外部命令、不记录网络内容；菜单栏使用紧凑的 `↓2.1k ↑1k` 形式。窗口双风扇读数采用 `3.2k · 3.4k R`，菜单栏采用 `3.5k R`，展开菜单和提示仍保留每个可读风扇的精确 `RPM`，读不到可拆分的电脑用电、充电输入或可靠摄氏度时，会明确显示不可用而不是估造数值。
风扇处于自动状态时，支持手动控制的滑条仍可直接拖动；第一次拖动会自动开启手动风扇并沿用低速警告与管理员授权，授权过程中仍可继续拖动，授权完成后采用最后停下的位置；恢复自动温控时点击风扇开关即可。

> **安全提醒：** 低于 50% 会先明确警告，0% 会要求所有可控风扇停止。芯片达到 99°C 时，任何手动转速都会恢复自动温控；低速时 macOS 热状态升高，或任何转速下遇到严重高温、App 退出及异常结束，也会恢复自动温控。低速仅适合开盖、通风、轻负载时短时使用，合盖续跑不适合在密闭包内进行高负载工作。

## 使用

支持 macOS 13+，通用包同时包含原生 `arm64` 与 `x86_64`。Apple 芯片会直接运行 ARM64，不依赖 Rosetta；无风扇 Mac 自动禁用风扇控制，无电脑盖的桌面 Mac 自动禁用合盖运行，但仍可使用低功耗和可读遥测。Intel 已通过编译、最低系统版本、打包和 Rosetta x86_64 功能运行检查，手动风扇、温度、电源与真实合盖行为仍需 Intel 真机验证。完整边界见[兼容性说明](docs/COMPATIBILITY.md)。

点击窗口左上角红色关闭按钮只会隐藏窗口，任务、模式与菜单栏读数会继续运行。App 会保留在 Dock 并显示运行点；点 Dock 图标可恢复窗口，右键 Dock 图标选择“退出”或使用菜单栏“退出软件”才会彻底结束。

如果在电源或风扇切换过程中请求退出，App 会先完成当前安全切换，再自动退出。电源设置、手动风扇和合盖调暗的内屏分别有异常退出恢复记录；下一次开盖或启动时会继续处理未完成的恢复。

启动、隐藏与恢复使用短促的淡入淡出和轻微位移动效；黄色按钮保留 macOS 原生最小化，开关、风扇模式与设置弹窗保持原生反馈。系统开启“减少动态效果”时，App 会自动取消位移动画。

App 会阻止第二个副本同时运行，避免多个进程竞争电源或风扇控制。

公开测试包采用 ad-hoc 签名，从网络下载后通常会被 Gatekeeper 拦截首次打开，只适合知道如何在“隐私与安全性”中确认的技术测试者。面向普通用户分发必须使用 Developer ID、强化运行时、苹果公证和 stapling。

## 构建

```bash
./scripts/build.sh
```

生成经过测试的通用架构发布包。脚本会同时生成 ZIP 备用包和标准 macOS 拖拽式 DMG；打开 DMG 后，把 `LitRun!.app` 拖到旁边的 `Applications` 图标即可安装到“应用程序”：

```bash
./scripts/package_release.sh
```

如果还要把同一份已验收的 ZIP、DMG 及各自校验文件复制到本地交付目录，可显式设置 `RELEASE_COPY_DIR`；不设置时只写入 `dist/`：

```bash
RELEASE_COPY_DIR='/path/to/release-folder' ./scripts/package_release.sh
```

在 Intel Mac 原生运行，或在 Apple 芯片上通过 Rosetta 运行独立的 x86_64 功能测试：

```bash
./scripts/test_x86_64.sh
```
